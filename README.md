# MiniMax-H3 Gradio WebUI

專為 **MiniMax-H3** 全模態音視訊聯合生成模型量身打造的輕量化 WebUI。支援手機瀏覽器連線，操作介面簡潔、響應迅速，免除在手機上操作 ComfyUI 龐大節點畫布的困擾。

---

## ✨ 核心功能特色

1. **三大生成模式**：
   * **🖼️ 圖+文生影片 (I2V / fl2va)**：上傳首幀（必填）與尾幀（選填），模型自動推演中間連續動作，支援首尾平滑過渡。
   * **✍️ 純文生影片 (T2V / t2va)**：無須參考圖，純文字提示詞驅動高解析度影片與立體聲生成。
   * **🎬 影片生影片 (R2V / ref2va)**：支援上傳最多 4 張參考圖、1 段參考影片（提取動作與特徵）及參考音訊，提示詞內可使用 `<Picture 1>`、`<Video 1>` 進行精確素材錨定。
2. **原生音視訊同步 (Audio-Video Joint)**：
   * MiniMax-H3 在生成畫面的同時直接運算立體聲音效（語音、環境音、背景音樂），生成的影片自帶同步音軌。
3. **手機介面高度適配 (Mobile Responsive)**：
   * 觸控大按鈕、滑動選單、自適應寬度，在 iPhone Safari 與 Android Chrome 皆可順暢操作。
   * 即時顯示手機在區網內的連線網址（如 `http://192.168.X.X:7860`）。
4. **完整參數開放**：
   * 包含自訂寬高、秒數時長（自動精確對齊 MiniMax 的 `17k + 5` 幀數規則）、隨機種子、取樣步數、去噪強度、調度器、取樣器與模型名稱切換。

## 🚀 快速啟動

### 1. 啟動 WebUI
在 `F:\program_file\AI_webUI` 資料夾中，提供兩種啟動方式：
* **一般模式 (`run.bat`)**：穩定正式運行。
* **開發熱重載模式 (`run_dev.bat`)**：儲存修改 `.py` 檔案時，Gradio 會**自動熱重載網頁**，無須重啟終端機。

### 2. 啟動 ComfyUI 後端
* WebUI 首頁頂部已內建 **「⚡ 啟動 ComfyUI 後端」** 按鈕。
* 若後端尚未啟動，直接點擊該按鈕，系統便會自動在背景以 `--listen 0.0.0.0` 啟動 ComfyUI，並自動掛載 `F:\Comfy_models` 模型庫！
* 亦可點擊 **「🔄 刷新連線狀態」** 確認後端是否就緒。

啟動後，終端機會顯示您的區網連線網址，例如：
```text
==========================================================
🚀 MiniMax-H3 Gradio WebUI 正在啟動...
📡 電腦本機存取: http://127.0.0.1:7860
📱 手機內網存取: http://192.168.1.100:7860
⚙️ 連結 ComfyUI 後端: http://127.0.0.1:8188
==========================================================
```

## 📱 手機連線說明

1. **同一個 Wi-Fi 網路**：請確認手機與電腦連接在同一個家用 Wi-Fi 基地台下。
2. **網址請輸入 `http://`**：
   * 手機瀏覽器網址列請完整輸入：`http://192.168.X.X:7860`
   * ⚠️ **請勿輸入 `https://`**，否則瀏覽器會回報「這個網站無法提供安全連線」。
3. **防火牆設定**：
   * 若手機無法開啟網頁，請至 Windows Defender 防火牆放行連接埠 `7860`（TCP）。

├── config.py               # 伺服器配置、預設模型名稱、解析度預設值

├── requirements.txt        # Python 相依套件列表
├── .gitignore              # Git 忽略設定
